## 2. 分层架构
| 层级 | 组件 | 功能描述 |
|------|------|----------|
| 接入层 | API Gateway | 统一入口、路由分发、鉴权限流 |
| 服务层 | 业务微服务 | 具体业务功能实现 |
| 支撑层 | 配置中心
注册中心
消息队列 | 提供运行时配置管理
服务注册发现
事件驱动支持 |
| 数据层 | MySQL
Redis
Elasticsearch | 结构化数据存储
缓存服务
搜索服务 |

## 3. 核心组件
- **网关服务**：Spring Cloud Gateway实现
- **认证中心**：OAuth2 + JWT实现
- **组织服务**：RBAC权限模型
- **系统管理**：配置管理/监控告警

## 4. 技术特性
- 前后端分离架构
- 容器化部署
- 自动化CI/CD流水线
- 多环境配置管理
